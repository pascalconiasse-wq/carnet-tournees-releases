# Carnet de tournées — installation Android

Appli de saisie des relevés des tournées de stations hydrométriques.

## Installer ou mettre à jour

Sur le téléphone Android, ouvrez ce lien et installez le fichier téléchargé :

**https://raw.githubusercontent.com/pascalconiasse-wq/carnet-tournees-releases/main/CarnetTournees.apk**

Si Android le demande, autorisez l'installation d'applis inconnues pour votre navigateur.

Une fois installée, l'appli prévient d'elle-même quand une nouvelle version est disponible.
Les mises à jour s'installent par-dessus l'ancienne version : les relevés sont conservés.
